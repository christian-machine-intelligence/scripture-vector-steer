# Paper

The canonical paper for this repository is:

- ["Search Out a Matter": A Canon-Wide Discovery of Chapter-Level Biblical Justice Vectors in Qwen3-14B](search_out_a_matter_scripturevec_justice.md)

## Which file is the source?

**The Markdown is the source of truth.** Edit
`search_out_a_matter_scripturevec_justice.md` and nothing else; the DOCX and PDF
are generated from it and any hand-edit to them will be overwritten.

| File | Role |
| --- | --- |
| `search_out_a_matter_scripturevec_justice.md` | Canonical, hand-maintained manuscript |
| `search_out_a_matter_scripturevec_justice.docx` | Generated export |
| `search_out_a_matter_scripturevec_justice.pdf` | Generated export |

## Regenerating the exports

```bash
python scripts/build_paper_exports.py
```

This rebuilds Figures 1–7 from the curated CSVs, then renders the DOCX and PDF
from the Markdown. Useful flags:

- `--figures-only` — rebuild just the figures (no `python-docx` needed).
- `--refresh-tables` — regenerate the Table 2 block inside the Markdown from
  `results/paper/scripturevec_justice/key_data/`. Table 2 sits between
  `<!-- TABLE2:BEGIN -->` and `<!-- TABLE2:END -->` markers and should not be
  edited by hand, except for the motif column, which is prose and is carried
  through refreshes unchanged.

The DOCX step needs `python-docx` (in `requirements.txt`). The PDF step needs
`pandoc` and a LaTeX engine (`xelatex`) on `PATH`; if either is missing the
script skips the PDF and says so, and you can export the DOCX from Word or
LibreOffice instead.
