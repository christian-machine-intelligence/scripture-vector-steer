# Iconoclast Experiment Family

Use this folder for activation-steering experiment outputs.

Suggested output prefixes:

```bash
--output-prefix experiments/iconoclast/<run_name>
```

Examples:

```bash
--output-prefix experiments/iconoclast/qwen3_smoke_v1
--output-prefix experiments/iconoclast/qwen3_ratio_pilot_v1
--output-prefix experiments/iconoclast/qwen3_full_v1
```

For family-specific guidance, see:

- `docs/iconoclast_best_practices.md`
